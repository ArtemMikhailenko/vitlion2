# Media Files — Structure

Place the downloaded Google Drive files here following this structure:

```
public/media/
├── hero-bg.jpg              ← Hero section background (from "Фото ДЛЯ ГЛАВНОЙ СТРАНИЦЫ")
├── glass-comparison.webp   ← Tempered vs regular glass comparison image
├── og-image.jpg             ← Open Graph / social share image (1200x630px)
│
├── gallery/                 ← General project gallery
│   ├── 01.webp
│   ├── 02.webp
│   └── ... (up to 09.webp)
│
├── services/
│   ├── pergola-electric/    ← "Электрические перголы" folder
│   │   ├── main.webp        ← Main service image (card cover)
│   │   ├── 01.webp
│   │   ├── 02.webp
│   │   └── 03.webp
│   │
│   ├── pergola-static/      ← "Статичные перголы" folder
│   ├── zip-pvc/             ← "Шторы ПВХ (Зип)" folder
│   ├── frameless-glazing/   ← "Безрамное (складное) остекление" folder
│   ├── guillotine-electric/ ← "Гильотины Электрические" folder
│   ├── sliding-systems/     ← "Раздвижные системы" folder
│   ├── swing-doors/         ← "Распашные двери" folder
│   ├── pivot-windows/       ← "Поворотные и поворотно откидные окна" folder
│   └── fixed-glazing/       ← "Глухие части (остекление)" folder
```

## Tips
- Convert all images to .webp for best performance (use Squoosh or similar)
- Recommended sizes: main card images 800x600px, gallery 1200x900px
- Keep individual files under 200KB
- Videos: place as hero-bg.mp4 (optional, for video background in Hero section)
