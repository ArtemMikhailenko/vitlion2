# Vitlion Group. Редиректы и канонизация

## 1. Языковая структура

Иврит - основной язык и корень сайта (без префикса), так как на иврите наибольшая частотность запросов (44 710/мес против 1 100/мес на русском и английском вместе). Русская и английская версии - с префиксами.

```
/                              ивритская версия (корень)
/ru/                           русская версия
/en/                           английская версия
```

## 2. Редиректы языкового префикса

Если пользователь или бот заходит по URL с ивритским префиксом `/he/` - редирект на корень без префикса (301). Ивритская версия не должна иметь префикс `/he/`, чтобы не было дублей.

```
/he/                    ->  /                    (301)
/he/services            ->  /services            (301)
/he/electric-pergolas   ->  /electric-pergolas   (301)
/he/static-pergolas     ->  /static-pergolas     (301)
/he/zip-shutters        ->  /zip-shutters        (301)
/he/glazing             ->  /glazing             (301)
/he/glass-roofs         ->  /glass-roofs         (301)
/he/about               ->  /about               (301)
/he/projects            ->  /projects            (301)
/he/contact             ->  /contact             (301)
```

## 3. Реализация на Tilda

Tilda не поддерживает серверные редиректы напрямую в базовом тарифе так же гибко, как React Router. Варианты:

- Через настройки домена / DNS-провайдера (если домен управляется отдельно) - настроить 301 на уровне хостинга/CDN (например Cloudflare Rules).
- Через Tilda "Перенаправления" (Настройки сайта -> Ещё -> Перенаправления) - добавить правила для `/he/*`.
- JS-редирект как запасной вариант (менее предпочтителен для SEO, но работает).

Пример JS-редиректа (вставляется в head через Tilda):

```html
<script>
  (function () {
    var p = window.location.pathname;
    if (p.indexOf('/he/') === 0) {
      var clean = p.replace('/he', '') || '/';
      window.location.replace(clean + window.location.search);
    }
  })();
</script>
```

## 4. Канонизация домена

Настраивается на уровне DNS/хостинга или в настройках Tilda. Выбран вариант с www (текущий рабочий адрес сайта - www.vitlion.co.il).

```
http://vitlion.co.il/*         ->  https://www.vitlion.co.il/*    (301)
http://www.vitlion.co.il/*     ->  https://www.vitlion.co.il/*    (301)
https://vitlion.co.il/*        ->  https://www.vitlion.co.il/*    (301)
```

Итоговый канонический вид: https + www.

## 5. Canonical теги

Каждая страница содержит canonical, указывающий на себя (в каноническом виде: https + www).

```html
<link rel="canonical" href="https://www.vitlion.co.il/electric-pergolas" />
```

Для главной, `/about`, `/projects` и `/contact` canonical не критичен, так как эти страницы закрыты в robots.txt.

## 6. Базовые правила

- Все редиректы постоянные (301).
- Канонический домен: с www, https.
- Ивритская версия - корень, без префикса `/he/`.
- x-default (в hreflang) всегда указывает на ивритскую (корневую) версию.
- Трейлинг-слэш: выбрать один вариант и придерживаться на всём сайте.
- Закрытые от индексации страницы (`/`, `/about`, `/projects`, `/contact`) canonical не требуют, но должны быть доступны по одному каноническому адресу без дублей www/без www.
