# Vitlion Group. Архитектура сайта

## Домен

```
https://www.vitlion.co.il
```

## Закрыты от индексации

```
/                       Главная страница (промо, не каталог)
/about                  О компании
/projects               Проекты / портфолио
/contact                Контакты
```

## Открыты для индексации (посадочные страницы)

```
/services               Все продукты (общий каталог)
/electric-pergolas      Электрические перголы
/static-pergolas        Статичные перголы
/zip-shutters           ZIP-роллеты
/glazing                Остекление (включая гильотины)
/glass-roofs            Стеклянные крыши
```

## Карточки внутри категорий

Не отдельные URL, а фильтры/якоря внутри страницы категории.

```
/electric-pergolas
├── ביוקלימטיק
├── ביוקלימטיק Bio Rolling
├── ביוקלימטיק רפרפה
├── ביוקלימטיק שלבי זכוכית
├── פרגולת PVC
└── פרגולת PVC קשתית

/static-pergolas
├── פרגולה קלאסית
├── פרגולה מפנל מבודד
├── פרגולה הייטק פס ישר
└── פרגולה הייטק פסים מעוצבים

/zip-shutters
├── מסכי ZIP
└── ZIP אופקי

/glazing
├── זכוכיות נאספות (основной блок)
├── זכוכיות נאספות עם צלון קלוע
└── גיליוטינה

/glass-roofs
├── סקיילייט חשמלי
└── גג זכוכית קבוע
```

## Дерево

```
/                        (Главная - закрыта от индексации)
├── /about               (О компании - закрыта от индексации)
├── /projects            (Проекты - закрыта от индексации)
├── /contact             (Контакты - закрыта от индексации)
└── /services            (Каталог - открыт)
    ├── /electric-pergolas    Электрические перголы
    ├── /static-pergolas      Статичные перголы
    ├── /zip-shutters         ZIP-роллеты
    ├── /glazing              Остекление (включая гильотины)
    └── /glass-roofs          Стеклянные крыши
```
