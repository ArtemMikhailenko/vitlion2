# Vitlion Group — Landing Page

Landing page for Vitlion Group, an aluminum construction company based in Israel. Built with React + TypeScript + Vite.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- i18next (Hebrew / Russian)
- react-helmet-async

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
```

Output goes to `dist/`.

## Languages

Switch between Hebrew (`?lang=he`) and Russian (`?lang=ru`) via URL param. Hebrew is RTL, Russian is LTR.
